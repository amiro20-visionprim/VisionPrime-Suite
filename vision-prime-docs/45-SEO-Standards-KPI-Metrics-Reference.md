## ۱) عناصر On-Page SEO (کنترل‌پذیر در محتوا)

| # | عنصر | جزئیات | هدف کمّی | اولویت | قابل سنجش |
|---|------|--------|----------|--------|------------|
| ۱ | H1 Tag | دقیقاً ۱ بار، شامل کلیدواژه اصلی | count = 1 | حیاتی | ✅ |
| ۲ | H2 Tags | ۳-۱۰ عدد، هرکدام یک زیرموضوع مستقل | 3 ≤ count ≤ 10 | حیاتی | ✅ |
| ۳ | H3 Tags | زیرمجموعه H2، حداکثر ۳-۴ در هر H2 | 0 ≤ count ≤ 30 | مهم | ✅ |
| ۴ | Meta Title | ۳۰-۶۰ کاراکتر، کلیدواژه در ۳۰٪ اول | 30 ≤ len ≤ 60 | حیاتی | ✅ |
| ۵ | Meta Description | ۱۲۰-۱۶۰ کاراکتر، CTA + کلیدواژه | 120 ≤ len ≤ 160 | حیاتی | ✅ |
| ۶ | URL/Slug | کوتاه، شامل کلیدواژه، بدون پارامتر | len ≤ 75, no params | حیاتی | ✅ |
| ۷ | کلیدواژه اصلی | در H1 + اولین پاراگراف + حداقل ۲ H2 | density 1-3% | حیاتی | ✅ |
| ۸ | کلیدواژه‌های LSI | کلمات مرتبط معنایی، پراکنده در متن | ≥ 5 unique LSI | مهم | ✅ |
| ۹ | پاراگراف مقدمه | ۲-۳ خط، hook + کلیدواژه | ≤ 100 words | حیاتی | ✅ |
| ۱۰ | طول محتوا | بستگی به رقابت (جدول زیر) | ≥ 1500 words | حیاتی | ✅ |
| ۱۱ | لینک‌های داخلی | حداقل ۲-۵ لینک به صفحات مرتبط | 2 ≤ count ≤ 10 | مهم | ✅ |
| ۱۲ | لینک‌های خارجی | ۱-۳ لینک به منابع معتبر (.gov/.edu) | 1 ≤ count ≤ 3 | مهم | ✅ |
| ۱۳ | تصاویر + Alt Text | حداقل ۱ تصویر با alt مرتبط | count ≥ 1 | مهم | ⚠️ |
| ۱۴ | جدول مقایسه | حداقل ۱ جدول برای محتوای مقایسه‌ای | count ≥ 1 | متوسط | ✅ |
| ۱۵ | لیست‌ها (UL/OL) | bullet/numbered lists برای نکات کلیدی | count ≥ 1 | مهم | ✅ |
| ۱۶ | Bold/Strong | کلیدواژه‌ها و نکات کلیدی bold | count ≥ 3 | متوسط | ✅ |
| ۱۷ | FAQ Section | سوالات متداول با Question/Answer | count ≥ 3 | مهم | ✅ |
| ۱۸ | CTA | حداقل ۱ دعوت به اقدام | count ≥ 1 | مهم | ✅ |
| ۱۹ | نتیجه‌گیری | خلاصه نکات + لینک داخلی | وجود داشته باشد | متوسط | ✅ |
| ۲۰ | Table of Contents | فهرست مطالب با anchor links | وجود داشته باشد | متوسط | ⚠️ |

| SpamBrain | سیستم ضد اسپم هوشمند | تکرار محتوا + keyword stuffing = جریمه |
