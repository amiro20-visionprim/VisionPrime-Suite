## D1 — دارک‌مود

### D1-01 — توکن‌های دارک در `resources/css/app.css`
**وضعیت:** ✅ انجام شد
**هدف:** حالت دارک بر پایهٔ توکن‌های سمنتیک (نه کلاس‌های پراکنده).
- [x] افزودن `@custom-variant dark (&:where(.dark, .dark *));` بعد از import ها (دارک‌مود کلاسی Tailwind v4).
- [x] تعریف بلوک `.dark { ... }` که متغیرهای `--color-*` را برای حالت تاریک اورراید کند:
  - سطح‌ها: `canvas`، `surface`، `surface-muted` (سلسله‌مراتب آبی-تیره یکدست، مثلاً `#0a101c / #111a2c / #182338`).
  - متن: `ink-strong`/`ink`/`ink-muted` → خانوادهٔ روشن (مثلاً `#e8eef7 / #a8bcd4 / #7d92ad`).
  - خطوط: `line`/`line-strong` → تیره‌تر از سطح (مثلاً `#22304a / #2e405e`).
  - وضعیت‌ها: جفت‌های `-50`/`-600`/`-700` برای success/warning/danger/info با هم flip شوند (چون `bg-*-50` + `text-*-600` در UI جفت استفاده می‌شوند).
  - برند: `brand-500/600/700/900` کمی روشن‌تر برای کنتراست روی تاریک (دکمه با متن سفید همچنان درست بماند).
  - سایه‌ها (`shadow-card/panel/float`) → `rgb(0 0 0 / …)` تیره و عمیق‌تر؛ `glow`ها تیره‌تر.
  - `--vp-focus-ring` → نسخهٔ روشن برند.
- [x] `color-scheme: dark` در `.dark` (اسکرول‌بار و کنترلها native تطبیق کنند).
- [x] گرادیان برند و `bg-hero-grid` دست‌نخورده بمانند (روی تاریک هم خوب‌اند).
**قبولی:** با کلاس `dark` روی `<html>`، صفحه‌های هر دو پنل (آژانس + مشتری) بدون نیاز به `dark:` پراکنده، خوانا شوند؛ توکن‌های سمنتیک خودکار جابجا شوند.

### D1-02 — کنترلر تم `resources/js/lib/theme.ts`
**وضعیت:** ✅ انجام شد
**هدف:** حالت تم با ماندگاری و همگام‌سازی با سیستم.
- [x] نوع `ThemePreference = 'light' | 'dark' | 'system'` و کلید localStorage ثابت (`suite-theme`).
- [x] `getStoredPreference()` — خواندن امن از localStorage (fallback به `system`).
- [x] `resolveTheme(pref)` — رزولوشن `system` با `window.matchMedia('(prefers-color-scheme: dark)')`.
- [x] `applyTheme(pref)` — toggle کلاس `dark` روی `document.documentElement` + `style.colorScheme`.
- [x] `setThemePreference(pref)` — ذخیره + اعمال.
- [x] `initTheme()` — اعمال در بوت + `change` listener برای همگام ماندن حالت `system`.
**قبولی:** انتخاب کاربر بعد از رفرش حفظ شود؛ در حالت `system` با تغییر OS همگام بماند.

### D1-03 — اسکریپت ضد-فلش در `resources/views/app.blade.php`
**وضعیت:** ✅ انجام شد
**هدف:** جلوگیری از فلش روشن قبل از بوت Vue.
- [x] یک `<script>` کوچک inline در `<head>` که پیش از رندر، localStorage را می‌خواند و کلاس `dark` را روی `<html>` می‌گذارد (همان منطق D1-02، بدون import).
**قبولی:** با تم دارک ذخیره‌شده، اولین پینت صفحه تیره باشد (بدون فلش سفید).

### D1-04 — کامپوننت `VThemeToggle` در `shared/ui`
**وضعیت:** ✅ انجام شد
**هدف:** دکمهٔ جابه‌جایی دارک/روشن با آیکون خورشید/ماه.
- [x] آیکون‌های `sun` و `moon` به رجیستری `VIcon.vue` اضافه شوند.
- [x] کامپوننت: دکمهٔ گرد آیکونی؛ حالت فعلی از `theme.ts`؛ کلیک → toggle بین `dark`/`light` (با توجه به حالت `system` فعلی) + ذخیره.
- [x] `aria-label` فارسی («تغییر حالت روشن/تاریک»)، استایل یکدست با هدر (border-line + hover).
**قبولی:** کلیک، کل کلاس ظاهری (کلاینت + آژانس + مارکتینگ) را بدون رفرش جابه‌جا کند؛ انتخاب ماندگار باشد.
