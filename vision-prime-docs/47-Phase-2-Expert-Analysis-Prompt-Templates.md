# 47 — فاز ۲: تحلیل خودکار متخصص SEO + کتابخانه پرامپت

**تاریخ:** ۲۰۲۶-۰۸-۲۱
**وضعیت:** در حال اجرا
**هدف:** تحلیل خودکار محتوا توسط AI + ذخیره تحلیل + کتابخانه پرامپت

---

## ۱) خلاصه فاز ۲

| # | ماژول | هدف |
|---|-------|-----|
| ۲.۱ | SEOExpertAnalyzer | تحلیل ۵ خطی خودکار از محتوا |
| ۲.۲ | ذخیره تحلیل در draft | اتصال تحلیل به هر محتوا |
| ۲.۳ | PromptTemplate Library | کتابخانه پرامپت‌های آماده |

---

## ۲) جزئیات ماژول ۲.۱: SEOExpertAnalyzer

### درد:
> الان محتوا تولید میشه ولی **چرایی** و **نقاط قوت/ضعف** مشخص نیست. کاربر نمیدونه چرا محتوا خوبه یا بد.

### پادزهر:
> یک تحلیلگر خودکار که بعد از تولید، محتوا رو از ۷ زاویه بررسی کنه و یک خلاصه ۵ خطی بده.

### تسک‌ها:

| # | تسک | فایل | توضیح |
|---|------|------|-------|
| ۲.۱.۱ | ساخت SEOExpertAnalyzer.php | جدید | سرویس تحلیل خودکار |
| ۲.۱.۲ | تحلیل ۷ زاویه | درون سرویس | On-Page, E-E-A-T, Readability, Structure, Images, Freshness, Uniqueness |
| ۲.۱.۳ | تولید خلاصه ۵ خطی | درون سرویس | توسط AI (GapGPT) با پرامپت متخصص |
| ۲.۱.۴ | نقاط قوت و ضعف | درون سرویس | لیست bullet points |
| ۲.۱.۵ | توصیه‌های بهبود | درون سرویس | اقدامات عملی |
| ۲.۱.۶ | اتصال به ContentApiController | controller | اجرای تحلیل بعد تولید |
| ۲.۱.۷ | ذخیره در audit_log | model | اضافه کردن expert_analysis به audit_log |

---

## ۳) جزئیات ماژول ۲.۲: ذخیره تحلیل

### درد:
> تحلیل‌ها فقط نمایش داده میشن و ذخیره نمیشن. A/B Testing بدون ذخیره تحلیل معنی نداره.

### پادزهر:
> ذخیره expert_analysis در content_drafts.audit_log برای مقایسه و A/B Testing.

### تسک‌ها:

| # | تسک | فایل | توضیح |
|---|------|------|-------|
| ۲.۲.۱ | اضافه کردن expert_analysis به audit_log | ContentApiController | ذخیره تحلیل در JSON |
| ۲.۲.۲ | UI تحلیل متخصص | ArticleDraft/Create.vue | نمایش تحلیل در مرحله نتیجه |
| ۲.۲.۳ | API دریافت تحلیل | ContentApiController | GET /api/content/analysis/{id} |

---

## ۴) جزئیات ماژول ۲.۳: کتابخانه پرامپت

### درد:
> کاربر تازه‌کار نمیدونه چطوری پرامپت بنویسه. هر بار از صفر شروع میکنه.

### پادزهر:
> کتابخانه‌ای از پرامپت‌های آماده و مهندسی شده برای انواع محتوا.

### تسک‌ها:

| # | تسک | فایل | توضیح |
|---|------|------|-------|
| ۲.۳.۱ | Migration جدول prompt_templates | جدید | ذخیره پرامپت‌ها |
| ۲.۳.۲ | مدل PromptTemplate | جدید | Eloquent model |
| ۲.۳.۳ | Seed داده‌ها | Seeder | ۱۰-۱۵ پرامپت آماده |
| ۲.۳.۴ | API CRUD | controller | مدیریت پرامپت‌ها |
| ۲.۳.۵ | UI انتخاب پرامپت | ArticleDraft/Create.vue | لیست + انتخاب + ویرایش |
